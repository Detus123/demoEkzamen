1. Сервер

Используемые библиотеки: express, pg, cors, dotenv, jsonwebtoken

Файлы:
index.js - серверная логика
.env - переменные окружения
init.sql - Создание бд
ER-diagram.png - ER-diagram бд

Запуск:
cd server
node src/index.js

2. Клиент

Используемые библиотеки: react-router-dom

Файлы и папки:
assets - фотки для слайдера
components - повторяющиеся компоненты страниц
pages - страницы приложения
styles.css - стили приложения
App.jsx - роуты

Запуск:
cd client
npm run dev
